# ALBEDO-BOT

Bot WhatsApp modular dengan struktur folder yang siap dikembangkan.

## Struktur

- `src/commands` untuk command bot
- `src/handlers` untuk handler event dan message
- `src/services` untuk logic bisnis / downloader / AI / media
- `src/tools` untuk util umum
- `src/utils` untuk helper kecil
- `src/config` untuk konfigurasi
- `src/database` untuk koneksi dan repositori
- `storage` untuk file temporary dan media

## Mulai

```bash
npm install
npm start
```
